# 実験001: 先着3社モニター募集（1万円）

- 開始: Day 2（2026-10-10）予定 / 判定日: Day 14（2026-10-22）
- 担当: AI（LP・投稿文・提案書・制作） / パートナー（投稿・フォーム返信・入金確認）

## 仮説
小規模事業者・個人事業主は「定型作業の自動化」に1万円を払う。
X発信とLPだけで、14日以内に1件の受注を得られる。

## 判定基準
| 結果（Day 14時点） | 判定 |
|---|---|
| 受注1件以上 | 継続。2件目以降は価格を2〜3万円に上げる |
| 相談はあるが受注0件 | 修正。提案内容か価格がずれている → 相談内容を分析して見直す |
| 相談0件 | 修正。集客経路を変える（ココナラ出品、知人紹介、業種を絞る） |

## 稼働1〜2時間/日に合わせた設計
- 打ち合わせなし。フォーム → メール提案 → 制作 → 納品で完結させる。
- 作る仕組みは Google Apps Script ＋ Claude API に統一し、毎回の制作パターンを使い回す。
- 1件あたりの人間側の作業目標は合計2時間以内（連絡・確認のみ）。

## 公開前にパートナーがやること（外部アクション）
1. Googleフォームを作成する（質問項目は下記）
2. Xアカウントを開設する（`sns/x_launch.md`）
3. `docs/index.html` の `{{FORM_URL}}` `{{OPERATOR_NAME}}` `{{CONTACT_EMAIL}}` `{{X_HANDLE}}` を差し替える（値を伝えてもらえればAIが差し替える）
4. GitHub Pages を有効化する（Settings → Pages → Branch: `main` / Folder: `/docs`）

## Googleフォームの質問項目
1. お名前（必須）
2. メールアドレス（必須）
3. 業種（必須・自由記述）
4. 自動化したい作業を1つ教えてください（必須・自由記述）
5. その作業に1週間でどれくらい時間を使っていますか（選択: 〜30分 / 30分〜2時間 / 2〜5時間 / 5時間以上）
6. 普段使っているツール（複数選択: Gmail / Googleスプレッドシート / Excel / LINE公式 / Instagram / その他）
7. このページを知ったきっかけ（選択: X / note / 知人 / その他）

## 注意点
- 有料で受注する前に「特定商取引法に基づく表記」が必要になる可能性がある（ネット上で申込を受ける通信販売にあたる場合）。初受注までに整備する。
- 個人情報を含む業務は、Claude APIに送るデータの範囲を提案書に明記する。
