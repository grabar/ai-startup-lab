# X 開設キット（Day 2）

前提: パートナーは「AI活用に関心のある個人・平日1〜2時間稼働」。
→ 投稿は **1日1〜2本・予約投稿で完結** する設計にする。文案はすべてAIが作成し、パートナーはコピペして投稿するだけ。

## アカウント名（決定）
- 表示名: **AIと90日で起業する人｜業務自動化**
- ユーザー名候補: `ai_cofounder90` / `ai_ceo_90days` / `ai90_startup`（空いているものを上から順に）

選定理由: 「AIが共同創業者」という物語（発信）と「業務自動化」（売り物）の両方が名前だけで伝わるため。

## プロフィール文（決定）
```
元手1.5万円・期限90日。AIを共同創業者にして起業中🤖
稼げなかったらAIはクビ。
▶ 小さな会社の「面倒な作業」をAIで自動化しています
▶ 売上・失敗・プロンプトを毎日すべて公開
📮 先着3社モニター募集中↓
```
- リンク欄: LPのURL（GitHub Pages）
- 固定ポスト: 下の「初投稿」

## 初投稿（固定ポスト・決定）
```
今日から、AIを共同創業者にして会社をつくります。

・元手は1.5万円
・期限は90日
・90日でAIの利用料を稼げなかったら、AIはクビ（プロジェクト終了）
・目標は月商300万円の芽をつくること

事業の方針もAIが決めました。
「小さな会社の面倒な作業を、AIで自動化する」

売上も失敗も、毎日ここで全部公開します。
#BuildInPublic #AI起業
```

## 2本目（初投稿の直後にリプライでつなげる）
```
AIが最初に出してきた事業アイデアは3つ。

① AI起業の実況＋有料note
② 中小企業向けAI業務自動化の代行
③ 業種特化のAIミニツール

AIの判断は「②が本命、①は集客役」。
理由は計算でした。
月商300万円は、単価1,000円なら月3,000件。単価30万円なら月10件。
最初から低単価では間に合わない、と。
```

## 3本目（リプライ）
```
というわけで最初の実験です。

「先着3社・1万円でAI業務自動化を引き受けます」
（通常価格は5万円の想定）

問い合わせ返信・売上集計・SNS投稿づくりなど、
毎日の面倒な作業を1つ、AIで自動化します。

打ち合わせなし、フォームだけで相談できます👇
{{LP_URL}}
```

## 最初の1週間の投稿予定（1日1本）
| Day | テーマ | 狙い |
|---|---|---|
| 3 | AIが作ったLPを公開。「AIに作らせたら○分でできた」 | 制作の様子を見せて信頼を得る |
| 4 | AIに渡した最初の指示書（CLAUDE.md）を公開 | 保存・拡散される投稿 |
| 5 | 「自動化できる作業」診断：こんな作業は自動化向き5選 | 見込み客に役立つ情報 |
| 6 | 途中経過：問い合わせ数（0件でも正直に） | 実況の継続性 |
| 7 | 1週目のまとめと、AIの次の判断 | note記事への誘導 |

## 運用ルール
- 数字は実数のみ。0件なら「0件」と書く。
- お客様の社名・個人情報は投稿しない（事前に許可を取った場合を除く）。
- 「必ず儲かる」「誰でも月○万」などの誇大表現は使わない。
